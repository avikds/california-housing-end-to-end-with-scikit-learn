California Housing, End to End with Scikit-Learn

How it was built

Part 1: Get the Data and Split It Honestly

Download the California housing data the way the book does, bin income for stratified sampling, split off a test set before looking further, and explore correlations and ratio features on the training set only.

Part 2: A Preprocessing Pipeline That Cannot Leak

Separate features from labels, write a custom cluster-similarity transformer, and assemble a ColumnTransformer with imputation, log transforms, scaling, one-hot encoding and the geographic features, so every statistic is learned from training data only.

Part 3: Baselines Before Models

Define the metric, score a dummy predictor so every later number means something, and set up cross-validation so training-set scores stop lying.

Part 4: Models and Tuning

Wrap the preprocessing and a regressor into one pipeline, compare a linear model with a random forest under cross-validation, and tune the whole pipeline - clusters included - with RandomizedSearchCV.

Part 5: Evaluate Like You'll Be Asked To

Open the test set once, report the RMSE with a bootstrap confidence interval, read the feature importances by name, and look at the districts the model gets most wrong.

Part 6: Ship It

Save the fitted pipeline, reload it in a fresh function, and expose a predict function that takes raw districts - the same object that scored the test set is the one that serves.
